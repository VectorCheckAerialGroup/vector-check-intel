# VECTOR CHECK AERIAL GROUP INC. — ARMS runtime dependencies
#
# Every third-party module imported anywhere in the codebase must appear
# here. audit.py tier 0 cross-references this file against the actual
# imports and fails on any gap — see the note at the bottom.
#
# ---------------------------------------------------------------------------
# UPPER BOUNDS ARE DELIBERATE
# ---------------------------------------------------------------------------
# These lines were previously floor-only (">=" with no ceiling), which let a
# DigitalOcean rebuild adopt a new major version with zero code changes.
# That took the Tactical Hazard Stack down on 2026-10-28:
#
#   ImportError: pyarrow requires NumPy 2.0 or newer, found 1.26.4
#
# Root cause chain (verified against PyPI wheel metadata):
#   1. pyarrow is NOT a direct import — Streamlit pulls it in to serialise
#      DataFrames for st.table / st.dataframe, so it was unpinned here.
#   2. pyarrow 18+ requires the NumPy 2.x ABI at RUNTIME but declares no
#      numpy constraint in its metadata (confirmed for 18.1.0, 19.0.1,
#      20.0.0). pip cannot see the conflict and installs the broken pair.
#   3. numpy is held at 1.x here, so the first rebuild after pyarrow 18
#      shipped produced an install that fails at import.
#
# A transitive dependency with an undeclared runtime constraint is invisible
# to the resolver. The only defence is to name it explicitly and bound it.
#
# The durable fix is still a lock file from a `pip freeze` on the production
# container (audit roadmap item 5). This file is intent; the lock is the
# guarantee.
# ---------------------------------------------------------------------------
